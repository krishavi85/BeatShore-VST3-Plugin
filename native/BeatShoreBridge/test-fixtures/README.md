# Test fixtures

`reference_test_melody.wav` -- a synthesized 5.1s stereo reference melody
(48kHz/16-bit) with a KNOWN ground truth, for testing real polyphonic
transcription (Basic Pitch, via BeatShore Bridge's "Transcribe Piano/
Guitar") against an actual answer key instead of judging accuracy purely
by ear.

Generated by `make_reference_test.py` (additive synthesis: fundamental +
4 harmonics, ADSR envelope per note -- not a bare sine wave, since Basic
Pitch was trained on real instrument recordings and a pure tone is an
unrepresentative stand-in for the harmonic content it expects).

Content: a C-major arpeggio up and down (C4-E4-G4-C5-G4-E4, six notes,
0.45s each with clear gaps) followed by a held C-major triad
(C4+E4+G4, 1.2s) to also exercise polyphonic (chord) detection, not just
a monophonic line. Full note-by-note ground truth (MIDI pitch, start
time, duration) is in `reference_test_melody.ground_truth.json`.

## How to use it for the REAPER acceptance test

1. Insert a new audio track in REAPER, add `BeatShore Bridge` as an FX
   on it.
2. Drag `reference_test_melody.wav` onto that same track as a media item.
3. Confirm BeatShore Desktop is running and the plugin's header shows
   "Connected".
4. Play the track from the start through to the end (the plugin only
   analyzes its own rolling 10-second capture buffer, so playback must
   actually reach and pass the audio -- scrubbing the playhead past it
   without playing does not fill the buffer).
5. Open the Transcribe page, click "Transcribe Piano/Guitar".
6. Note the reported note count and open the exported MIDI file (path
   shown in the result / via "Open Export Folder") in REAPER or any MIDI
   viewer.
7. Compare against `reference_test_melody.ground_truth.json`: does the
   note count match (9 real note-events, though a polyphonic transcriber
   may reasonably merge the arpeggio's repeated G4/E4/C4 hits differently
   depending on how it segments the held chord); do the pitches match
   (C4/E4/G4/C5 = MIDI 60/64/67/72); are onset times within a reasonable
   tolerance (a few tens of ms) of the ground truth's `startSeconds`.
